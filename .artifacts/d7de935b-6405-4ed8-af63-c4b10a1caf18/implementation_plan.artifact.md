# ビデオライブ壁紙設定アプリの作成プラン

ダウンロードフォルダにある動画を、Androidのホーム画面やロック画面の「ライブ壁紙」として設定できるアプリを作成します。

## アプリの概要
- **動画選択**: ダウンロードフォルダから動画を最大20件読み込みます。
- **自動リサイズ**:
    - 縦画面の時は、動画の「高さ」を画面に合わせます。
    - 横画面の時は、動画の「幅」を画面に合わせます。
- **履歴機能**: 設定した動画を最大50件まで記憶します。
- **プレビュー**: 小さなスマホ画面のような見た目で、設定後のイメージを確認できます。
- **設定範囲**: 「ホーム画面のみ」「ロック画面のみ」「両方」から選べます。

## 技術的なポイント（中学生向け解説）
このアプリを作るために、以下の「部品」を使います：
- **WallpaperService（壁紙の魔法使い）**: Androidの裏側で「壁紙を表示し続ける」ための特別な仕組みです。
- **ExoPlayer（動画再生機）**: 動画を滑らかに再生するための高性能なプレイヤーです。
- **Jetpack Compose（画面の組み立てブロック）**: ボタンやリストなどの見た目を簡単に作るための最新ツールです。
- **Room（小さな記憶箱）**: 履歴などのデータを保存しておくためのデータベースです。

## 開発ステップ

### 1. プロジェクトの土台作り
新しいプロジェクトとして作成するため、以下の設定ファイルを準備します。
- `build.gradle.kts`: アプリに必要なライブラリ（動画プレイヤーやデータベースなど）を登録します。

### 2. 壁紙エンジンの作成
動画を背景で流し続けるための中心部を作ります。
- `VideoWallpaperService.kt`: ここで動画再生機を動かし、スマホの向きに合わせて動画の大きさを調整します。

### 3. 動画を探す仕組みの作成
「ダウンロード」フォルダから動画を見つけてくる機能を作ります。
- `VideoProvider.kt`: スマホの中の動画ファイルを検索し、リストにします。

### 4. 画面（UI）の作成
ユーザーが操作する画面を作ります。
- `MainActivity.kt`: 動画を選んだり、プレビューを見たりする画面です。
- `HistoryScreen.kt`: 過去に設定した動画を表示する画面です。
