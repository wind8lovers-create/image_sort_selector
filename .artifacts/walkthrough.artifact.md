# ビデオライブ壁紙設定アプリ 完成報告書

あなたのアイデアをもとに、動画をライブ壁紙として設定できるAndroidアプリのプロトタイプを完成させました。

## 実施した内容

### 1. ライブ壁紙エンジン (`VideoWallpaperService.kt`)
- **ExoPlayerの導入**: 動画再生のプロフェッショナルな道具を使い、滑らかな再生を実現しました。
- **自動リサイズ魔法**: スマホが縦向きなら上下を、横向きなら左右を画面端に合わせ、隙間なく動画を表示するロジックを実装しました。

### 2. インテリジェントな動画検索 (`VideoProvider.kt`)
- スマホの「ダウンロード」フォルダのみをスキャンし、最新の動画20件を素早くリストアップします。

### 3. 記憶の保管箱 (`VideoHistory.kt`, `AppDatabase.kt`)
- 過去に設定した動画を最大50件まで記憶するデータベースを構築しました。

### 4. ユーザーインターフェース (`MainActivity.kt`)
- **プレビュー窓**: スマホ風の枠で、動画の映り方を事前にチェックできます。
- **タブ切り替え**: 「フォルダ」と「履歴」をパッと切り替えて動画を選べます。
- **設定パネル**: 動画の好きな瞬間をキャプチャして、アプリの起動画面（表紙）に設定できる機能を追加しました。

## 技術の解説（中学生向け）
- **Compose (コンポーズ)**: 画面を「レゴブロック」のように組み上げる最新の技術を使いました。
- **Room (ルーム)**: スマホの中に「小さな図書館」を作り、履歴を大切に保管しています。
- **Intent (インテント)**: Androidシステムに「壁紙を変えてください！」とお願いする公式な手紙の仕組みを使っています。

## 動作確認の手順
1. Android Studioでプロジェクトを開き、実行ボタンを押します。
2. アプリが起動したら、動画アクセス権限を許可します。
3. リストから動画を選び、プレビューで確認します。
4. 「設定」タブで好きな瞬間を「起動画面」に保存してみてください。
5. 「壁紙に設定する」ボタンを押し、Androidの設定画面で適用します。

> [!TIP]
> 動画のキャプチャ機能を使う際は、プレビュー画面のシークバーを使って好きな位置で止めてから「設定」ボタンを押すと綺麗に撮れます！
